Table plugin

A grid driven by a column file, with a cell type supplied as an ordinary Weave component.

The columns below were fetched from public/json/documents.columns.json after this page mounted — the plugin was constructed with an empty list and picked them up when they landed. Change that file and reload: no rebuild.

Loading the configuration

Two routes, and the choice is about who gets to change a grid. A build-time import is bundled and type-checked against ColumnConfig; a runtime fetch lets a deployment change what a screen shows without shipping code, and pays for it with the plugin's own validation.

Columns

Switched off here, the column leaves the grid and the change is reported through the same onAction as everything else. Drag a grip to reorder — or focus one and press Space, then the arrows, then Space again.

Reprocessable is hideInMenu — listed and movable, but its checkbox is disabled, so it cannot be switched off. rawState is hidden — never rendered, and still in the file because other things read it. internalNote asks for a role this viewer does not hold, so it is absent from both the grid and this list.

The grid

The grid is wrapped in one element carrying use:tableRows. Click a row, double-click it, or right-click for its menu — all three arrive at the same onAction.

row.id }} sort={{ grid.sort() }} onSort={{ grid.onSort }} selectable virtual={{ grid.virtual() }} rowHeight={{ grid.rowHeight() }} overscan={{ grid.overscan() }} maxHeight={{ grid.maxHeight() }} headerRow={{ grid.headerRow() }} columnWidths={{ grid.columnWidths() }} onColumnResize={{ grid.onColumnResize }} resizableColumns ariaLabel="Documents" />

Rows carry classes from their own data — a failed or rejected document is tinted, a test document is marked. Drag a column edge to resize; the width is kept in the same preferences as the order and the visibility.

Pages

The grid holds one page. Moving reports the query for the next one — and changing a filter or the sort sends the reader back to page one, because staying on page 7 of a result set that no longer has seven pages is how a filter comes to look like it returned nothing.
