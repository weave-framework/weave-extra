What it does

Filter opens a control per column inside <thead>, so the boxes line up with their columns whatever the widths are. Type and press Enter, or pick from a list. The plugin filters nothing itself — it reports the query, and this page plays the server by applying it, which is exactly where your own fetch would go.

Right-click any column header for the columns panel: switch one off, or drag a grip to move it — a line shows where it will land. The grip also works from the keyboard with Space, the arrows, then Space. Reprocessable is hideInMenu — listed and movable, but not switchable. rawState is hidden, never rendered but still in the file because other things read it. internalNote asks for a role this viewer lacks, so it is in neither.

Rows take a click, a double-click and a right-click menu, and carry classes from their own data — failed and rejected documents tinted, test documents marked. Drag a column edge to resize; the width is kept with the order and the visibility.

Loading the configuration

Two routes, and the choice is about who gets to change a grid. A build-time import is bundled and type-checked against ColumnConfig; a runtime fetch lets a deployment change what a screen shows without shipping code, and pays for it with the plugin's own validation.
