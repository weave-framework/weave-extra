Docking

One configuration drives the whole layout — which edge the panel sits on, which axis the split runs along, and whether the panel is there at all.

One split, five configurations

Nothing in the markup is rewritten per dock position, and the component needs no new API: the configuration feeds a keyed {{ '@for' }}, so the panes really do reorder in the DOM instead of only being moved by the grid. Tab order follows DOM order, so that distinction is the difference between a separator a keyboard user can reach and one they cannot.

Drag the gutter, then dock the panel elsewhere — it keeps the share you gave it rather than inheriting whatever was on that side.
