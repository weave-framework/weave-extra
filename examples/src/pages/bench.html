Rendering cost

What a production-shaped grid actually costs: mostly text, a few dates and enums, component cells, and an action column — measured, not estimated.

Outside a batch Weave flushes synchronously, so rows.set(…) returns with the DOM already built. Build is that call. Paint is the frame the browser needs afterwards, taken with the double-requestAnimationFrame idiom.
